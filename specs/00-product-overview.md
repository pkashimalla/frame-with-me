# 00 — Product overview

## Name

**Frame With Me** (repo: `frame-with-me`)

## One-liner

Studios hire reliable photo/video crew for Indian weddings and events — assistants, second shooters, leads, cinematographers, drone, editors — via an **Android** mobile app with smart matching, offer queues, and UPI trust rails.

## Problem

Indian studios still staff overflow on WhatsApp / Instagram / Facebook groups:

- No calendar lock → double booking
- No deposit → no-shows on peak Saturdays
- Portfolio roulette → brand risk
- Multi-day weddings need 3–8 crew roles, not one freelancer

## Solution (ShootWith.Me model + India)

1. Talent sets profile, rates, gear, radius, availability
2. Studio creates a job/event and role need
3. Studio searches/filters talent and builds a queue
4. Ranked or Instant offers fill the seat
5. Messaging + reviews create accountability
6. **India add-ons:** UPI deposit, WhatsApp notify, multi-function events, day rates in INR, city GTM, agentic hiring assistant

## Primary users

| User | Goal |
|---|---|
| Studio owner / lead | Fill roles fast before Haldi / wedding / reception |
| Assistant | Get into industry, learn, earn |
| Second shooter | Fill calendar gaps, side income |
| Lead / associate | Cover dates for other studios |
| Specialist (India) | Cine, drone, reel shooter, editor |

## Platform (locked)

- **Android only** for v1 (see `09-android-platform.md`)
- iOS deferred until Hyderabad fill-rate proves product

## Non-goals (v1)

- iOS / App Store
- Consumer “book a wedding photographer” marketplace (WedMeGood / Urban Company territory)
- Full studio CRM (leads, GST invoices, albums) — stay focused on crew hiring
- Pan-India launch day one

## GTM

Hyderabad → Bengaluru → Chennai → Delhi NCR / North

## Principles

1. **Android-first** — freelancers accept jobs from the phone; studios hire on the go
2. **Liquidity over features** — fill Saturday jobs before building CRM
3. **Trust over vanity AI** — deposits and reviews beat flashy agents that book wrong people
4. **Low cost build** — Expo (Android) + Supabase + Razorpay; WhatsApp deep-link first, Cloud API later
