# Customer UX checklist (ease of use)

Use with `.cursor/agents/customer-perspective.md`.

## Studio
- [ ] Language choice before long forms
- [ ] “New call sheet” is the obvious primary action
- [ ] Lookbook shows work first, not spreadsheet rows
- [ ] Queue order understandable
- [ ] Ranked vs Instant explained in plain language
- [ ] Deposit amount visible before pay
- [ ] Errors localized and non-scary

## Freelancer
- [ ] Calendar open vs busy unmistakable (color + label)
- [ ] Offer countdown readable
- [ ] Accept / Pass are large and clear
- [ ] Bookings show deposit status simply

## Cross-cutting
- [ ] te/hi fonts render without tofu (□)
- [ ] No dead ends; always a next step or back
- [ ] Feels faster than hunting WhatsApp groups
- [ ] Looks ≥ wireframe quality (cinema-set)
