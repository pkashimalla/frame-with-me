# Wireframes — creative edition

Clickable Android prototype aimed at **photographers & videographers**.

## Open

```
wireframes/index.html
```

## Design direction

- **Cinema-set / darkroom** UI (matte black + bone + teal gel accent)
- Typography: **Instrument Serif** + **Sora**
- Language creatives know: *call sheet, lookbook, roster, roll camera*

## What’s innovative vs generic apps

| Pattern | Why creatives care |
|---|---|
| **Lookbook** hire cards | Hire by portfolio, not spreadsheet rows |
| **Call sheet** jobs | Feels like production, not “create ticket” |
| **Roster** (not Favorites) | Trusted bench language |
| **Crew queue** | Shot-list priority for ranked offers |
| **Live countdown offers** | Urgency without Uber spam |
| **Shoot calendar** | Open days = money days, visually |
| **EN / తెలుగు / हिन्दी** | Language on first run + Settings; live switch |

## Languages (try it)

1. Welcome → **Start shooting** → **Language** screen  
2. Tap **తెలుగు** or **हिन्दी** — UI + fonts update  
3. Or tap the **EN** pill on the phone → Settings · language  

Job notes / chat stay untranslated (user-typed). App chrome only.
